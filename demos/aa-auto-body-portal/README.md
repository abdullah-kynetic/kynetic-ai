# AA Auto Body Shop demo portal

Clickable sales demo. Static HTML/CSS/JS, English only, all data fake (see `data.js`). No backend, no logins, nothing is sent.

Redeploy (new Pages project `aa-portal-demo`, preview branch `demo`):

    npx wrangler@3 pages deploy demos/aa-auto-body-portal --project-name aa-portal-demo --branch demo

Preview: https://demo.aa-portal-demo.pages.dev
