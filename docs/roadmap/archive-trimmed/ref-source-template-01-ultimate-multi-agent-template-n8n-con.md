Uploaded by Abdullah Oct 5, 2026 as a candidate starting point for the outbound/inbound rebuild. n8n workflow JSON, Google Calendar backend (not Cal.com). Saved word for word.

**Architecture note:** this is the only artifact that CONSOLIDATES all Retell/Vapi custom-tool calls into ONE webhook + ONE "Main Scheduling agent" that reads an `action` param (booking/reschedule/cancel/check availability) and branches internally via Google Calendar tools, then on successful booking calls a separate "post call agent" as a nested AI Agent Tool (not a separate workflow) that sends confirmation email (Gmail), internal SMS (Twilio), and logs to Google Sheets. Compare to Emily's current setup (one Retell tool → one n8n webhook, each separate) and to SOURCE TEMPLATE 02/03 below (same non-consolidated pattern). See the build plan note for the recommendation on this tradeoff.
