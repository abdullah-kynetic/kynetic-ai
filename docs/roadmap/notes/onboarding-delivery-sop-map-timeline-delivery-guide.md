Internal build/deploy checklist per client, mapped to the 3 core systems.

**Pre-Build (Day 0-1):** Project Brief completed and reviewed, access collected, client workspace provisioned, demo/reference build reviewed for this niche.

**System 1 - Reputation Engine:** connect GBP, configure automated review request trigger, set up GBP auto-posting cadence, set up review response automation/alerting.

**System 2 - AI Speed-to-Lead Agent:** audit site speed, identify capture-form friction, implement fixes/rebuild landing page, verify mobile speed, configure Retell agent with services/hours/escalation rules, connect Twilio number, connect Cal.com, test inbound call -> qualify -> book -> confirmation SMS end to end, test emergency-branch opt-out handling explicitly (compliance-critical).

**System 3 - Lead Recovery & Nurture:** import client contact list, de-duplicate and tag by status/source, configure reactivation sequence, test send to internal number first, build nurture sequence per niche, confirm compliant opt-out language present, connect to CRM pipeline stages.

**QA Before Go-Live:** all 3 systems tested end-to-end by someone other than the builder, client-facing copy reviewed for brand voice, compliance guardrails signed off, client portal access confirmed.

**Go-Live:** walkthrough call scheduled, client portal credentials sent, monitoring/alerting on for first 7 days.

**Offboarding (if a client cancels):** export client's data within 15 business days, revoke Kynetic access to GBP/website/phone number, archive workspace for 90 days before deleting.
