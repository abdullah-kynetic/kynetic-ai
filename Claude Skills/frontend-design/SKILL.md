# Frontend Design Skill

Create distinctive, production-grade frontend interfaces that avoid generic AI aesthetics in favor of intentional, context-specific design.

## When to invoke this skill

- Building any React/Tailwind/CSS frontend component or page
- Designing a UI with a specific aesthetic direction
- Critiquing or improving an existing frontend for visual quality
- Asked to make a UI "look good", "feel premium", "match a brand", or "avoid generic AI design"
- Any frontend task where design quality matters, not just functionality

## Core approach

**Understand context before coding:**
1. What is the interface's purpose?
2. What tone and emotional register is appropriate?
3. What technical constraints exist?
4. What is the one memorable differentiator?

Then: "Choose a clear conceptual direction and execute it with precision."

## Design focus areas

**Typography:** Use distinctive, characterful typefaces. Pair display and body fonts deliberately for visual hierarchy. Avoid defaulting to Inter or system-ui.

**Color & motion:** Commit to a cohesive palette using CSS variables. Implement animations strategically — prioritize high-impact moments (staggered page load, key state transitions) over scattered micro-interactions.

**Spatial composition:** Use asymmetry, overlap, diagonal flow, and unexpected layouts that break grid conventions where appropriate.

**Visual atmosphere:** Layer textures, gradients, custom patterns, and decorative elements matching the aesthetic direction.

## What to avoid (generic AI aesthetics)

- Overused font families (Inter, Roboto)
- Cliché color schemes (purple gradients, generic blues)
- Predictable centered layouts
- Cookie-cutter card-grid patterns
- Equal rounding on every element

## Complexity matching

Maximalist vision → elaborate animations and layered visuals.
Minimalist vision → precision in spacing, typography, and restraint.
