# Canvas Design Skill

Create sophisticated, museum-quality visual art — posters, artwork, and static designs — delivered as PNG or PDF files. Two-phase process: design philosophy first, then visual expression.

## When to invoke this skill

- Creating a poster, visual artwork, or graphic design
- Generating a branded visual asset (PNG or PDF)
- Asked for a "design", "visual", "poster", "artwork", or "graphic"
- Any task where the output is primarily a visual artifact rather than a web page or document

## Process

### Phase 1 — Design Philosophy (mandatory)
Write a 4–6 paragraph aesthetic manifesto establishing:
- The conceptual direction and visual language
- How ideas manifest through form, color, space, and composition
- The intended emotional register and audience

The philosophy must repeatedly affirm that final work appears "labored over with care" and represents master-level execution.

### Phase 2 — Visual Expression
Create the single-page canvas (PDF or PNG) embodying the philosophy:
- ~90% visual design, ~10% essential text
- Text as visual element — never explanatory paragraphs
- Typography: thin, design-forward fonts; minimal and intentional
- All elements properly spaced with clear breathing room — **nothing overlaps, nothing falls off the page**
- Deliver: the visual artifact + the design philosophy as a markdown file

## Design standards

- **Visual-first**: Ideas communicate through spatial relationships and form, not text
- **Craftsmanship**: Every detail refined; work conveys countless hours of expert attention
- **Originality**: Never copy existing artists' work — creative freedom guides interpretation
- **Sophistication over decoration**: Deliberate, intentional aesthetic direction
- **Output quality**: Museum or magazine quality, regardless of subject

## Output

- Primary: PNG or PDF (single page)
- Companion: design philosophy as `.md` file

## Works alongside

`pptx` (visual language decisions), `frontend-design` (when translating to web UI).
