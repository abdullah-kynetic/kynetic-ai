## Sequence (one ask per message)
1. **Ask:** the subdomain, with its DNS A record already pointing to 40.160.150.91. If he has no preference, propose `docs.kyneticai.com` in that same single ask.
2. **Ask:** paste and run the installer, then send back the output. Build the paste block as:
   `cat > /tmp/docmost-install.sh <<'KYNETIC_EOF'` + the full contents of `install.sh` + `KYNETIC_EOF` + a final line `sudo bash /tmp/docmost-install.sh <domain>` (write the file first; don't pipe the script to `bash -s`).
   The installer stops on its own if RAM is under 2 GB available or disk is under 15 GB free, and makes no changes in that case. If it stops for that reason, tell him in one line and offer one option: a bigger VPS plan.
   It writes /opt/docmost (compose + `.env` 600), `docmost.service`, a Caddy block (validated, rolled back on failure), the nightly local backup at 02:20 with 14-day retention, and runs a restore test.
3. **Ask:** open https://<domain>, create the admin account and workspace "Kynetic AI", then create a space named "Client Template" and import `client-template.zip` into it. Send the file with SendUserFile. If Docmost import rejects the zip, have him import the six `.md` files instead.
4. **Ask:** paste the output of
   `sudo sed -E 's/((KEY|SECRET|TOKEN|PASS(WORD)?|CREDENTIAL)[A-Za-z_]*[=: ]+)[^ "'\'']+/\1<redacted>/Ig' /usr/local/sbin/twenty-backup.sh`

5. **Ask (approval):** "OK to add a 'Docmost Space' link field on Company and the onboarding step to the SOP note in Twenty?" On yes:
   - `create_field_metadata` on company: type LINKS, name `docmostSpace`, label "Docmost Space", icon `IconBook`.
   - Update the SOP note: add the bullet `- Create the client's Docmost space from the Client Template (https://<domain>), invite the client to that space only, and paste the space URL into the company's "Docmost Space" field`. Change no other text.
6. **Verify before client use (do it, then report only if there's a problem):** clients are workspace members who see only the spaces they're added to. Confirm with Abdullah, as one ask, that a test client account cannot see the Client Template or other spaces, and whether the member list exposes other clients. Docmost Community may not have guest roles.
7. **Finish:** update `KYNETIC_CONTEXT.md` (Docmost host, /opt/docmost, port 3010, backups), `docs/progress.md` log and `docs/decisions.md` (Docmost replaces Notion as the client portal; Twenty stays internal). Commit on branch `infra/docmost`, push, open the PR. Then send one update: done, with the PR link.
